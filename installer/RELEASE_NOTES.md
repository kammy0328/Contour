## DIAP 1.9.0 (이전 이름 Contour)

**이름과 설치 위치**
- 프로그램 이름이 DIAP로 바뀌었습니다. 이제 `C:\Program Files\Diap`에 설치됩니다. 1.8.1(사용자 폴더 설치)은 설치가 끝나면 자동으로 지워집니다.
- 관리자 권한이 필요해서, 업데이트할 때 Windows 권한 확인 창이 뜹니다.
- 기존 `문서\Contour_Data`(학습 데이터, 프리셋, 모델)는 그대로 이어서 씁니다.

**피부 보정 마스크**
- 얼굴 영역 분석(SegFormer 얼굴 파싱)을 추가했습니다. 피부, 목, 머리카락, 옷, 얼굴을 가린 물체를 픽셀 단위로 구분합니다.
  - 목 마스크가 셔츠, 옷깃, 목걸이, 손으로 번지지 않습니다.
  - 손, 소매, 응원봉이 얼굴을 가린 부분에는 보정이 들어가지 않습니다 (밝은 장면에서 가장 정확합니다).
- 마스크 떨림을 줄였습니다.
  - 랜드마크를 화면 움직임에 맞춰 앞뒤 프레임과 함께 안정화합니다.
  - 피부색 기준, 머리카락 판별, 어깨 위치를 시간축으로 고정합니다.
  - 마스크를 얼굴 움직임에 맞춰 앞뒤 2프레임과 평균합니다. 가림이 생긴 프레임에서는 그 프레임의 판단을 따릅니다.
  - 목 마스크가 프레임마다 켜졌다 꺼지던 현상이 사라졌습니다.
- 처음 쓸 때 얼굴 분석 모델(약 340MB)을 한 번 받습니다. 1.9 이전에 분석한 컷은 열거나 렌더할 때 얼굴 영역 분석을 자동으로 한 번 실행합니다 (다시 분석할 필요 없음).

**비상업적 용도 전용**: 얼굴 분석 모델과 학습 데이터(CelebAMask-HQ)는 비상업적 사용만 허용됩니다.
