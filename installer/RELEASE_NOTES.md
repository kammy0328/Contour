## DIAP 1.13.4

**작업 상태 표시와 변경**
- 썸네일의 초록 체크를 없앴습니다. 분석 여부는 상태 라벨로 구분합니다. (분석 실패는 빨간 `!`로 그대로 표시)
- 작업 전 / 작업 중 / 작업 불필요 / 완료를 색과 아이콘으로 구분합니다. 작업 전은 주황 채움, 작업 중은 파랑, 작업 불필요는 회색 윤곽선이고 썸네일도 어둡게 보입니다.
- 컷 목록과 하단 타임라인의 상태 라벨을 클릭하면 작은 메뉴로 상태를 바꿉니다. 컷을 여러 개 선택한 채 누르면 선택한 컷 모두에 적용됩니다. 메뉴에는 자동(분석·보정 상태에 따름)도 있습니다. 우클릭 메뉴는 그대로 쓸 수 있습니다.

**미리보기**
- "나란히"를 "비교"로 이름을 바꿨습니다.
- 비교 모드에서 확대하면 한쪽 사진이 다른 쪽 영역을 덮던 문제를 고쳤습니다. 각 사진은 자기 영역 안에만 그려지고, 라벨도 영역 모서리에 고정됩니다.
- 와이프 경계선이 화면에 고정됩니다. 확대·이동해도 선이 움직이지 않고 항상 잡을 수 있습니다.
- 가운데 버튼 이동과 휠 확대에서 사진이 화면 밖으로 사라지지 않습니다. 전체 크기까지 축소하면 중앙 맞춤으로 돌아옵니다. 비교 모드로 들어가고 나올 때는 화면에 맞춰 다시 정렬합니다.

**분석 창 이름**
- 컷을 골라 분석할 때 창 제목이 "선택 컷 분석"으로 나옵니다. (전체 분석 버튼은 "전체 분석")
