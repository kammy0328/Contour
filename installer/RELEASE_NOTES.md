## DIAP 1.10.0

**피부 · 몸매 탭**
- 오른쪽 패널의 `보정` 탭을 `피부`와 `몸매`로 나눴습니다.
- `피부` 탭은 `기본 조정`과 `세부 조정`으로 나뉩니다. 기본 조정에서 보정 강도(약하게 / 표준 / 강하게)와 입가주름·팔자주름·여드름의 보호 / 제거를 고르면 세부 조정 슬라이더에 값이 바로 들어갑니다. 세부 조정에서 값을 바꾸면 기본 조정의 선택 표시가 해제됩니다.
- 표준 강도는 피부결 70(엔진의 기준값), 약하게는 45, 강하게는 90입니다. 표 전체는 README의 1.10.0 항목에 있습니다.

**시작, 열기, 저장, 업데이트**
- 실행하면 바로 로딩 화면(로고와 회전 애니메이션)이 뜹니다.
- 프로젝트를 여는 동안 창이 멈추지 않고 진행 상황이 나옵니다.
- 자동 저장은 복구본만 만들고, 프로젝트 파일은 저장할 때만 바뀝니다. 저장하지 않고 닫으면 저장 / 저장 안 함 / 취소를 묻고, 저장하지 않고 프로그램이 끝났으면 다음에 열 때 복구할지 묻습니다.
- 설정에 `시작할 때 새 버전 확인`(기본 켬)을 추가했습니다.

**보정과 분석 (1.9.1 ~ 1.10.0)**
- 피부결 보정을 손 보정 레퍼런스에 맞춘 방식으로 바꿨습니다. 모공·패임·요철을 같은 비율로 줄이고 원본 그레인은 남깁니다.
- Log 영상(S-Log3, ARRI LogC3, LogC4)은 원본에서 계산합니다.
- 인물 분할을 SAM 3.1로 바꿨습니다(처음 분석할 때 모델 약 940MB를 받습니다). 정체 뒤바뀜 교정, 놓친 인물 추가(`(추가)`, 보호로 시작), 사진 판정을 개선했습니다.
- H.264 MP4 bake에서 컷이 한 프레임 앞에서 시작하던 문제와, ffmpeg 9에서 프록시 색이 깨지던 문제를 고쳤습니다.
- 피부 마스크 계산이 군중 컷에서 약 22% 빨라졌습니다(결과는 같음).
- 검증: ILLIT 1013_4444XQ 37컷, lngshot 'wanna go' v3 105컷.

프로젝트, 학습 데이터, 프리셋, 모델은 그대로 남습니다. 업데이트할 때 Windows 권한 확인 창이 한 번 뜹니다.
