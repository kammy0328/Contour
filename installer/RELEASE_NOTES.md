## DIAP 1.9.0 (이전 이름 Contour)

**이름과 설치**
- 프로그램 이름이 DIAP로 바뀌었고 `C:\Program Files\Diap`에 설치됩니다. 1.8.1(사용자 폴더 설치)은 설치가 끝나면 자동으로 지워집니다.
- 작업표시줄과 작업 관리자에 DIAP 아이콘과 이름이 나옵니다 (DIAP.exe).
- Program Files라서 업데이트할 때 Windows 권한 확인 창이 한 번 뜹니다.
- 기존 `문서\Contour_Data`(학습 데이터, 프리셋, 모델)는 그대로 이어서 씁니다.

**피부 보정**
- 얼굴 영역 분석(SegFormer 얼굴 파싱): 피부, 목, 머리카락, 옷, 얼굴을 가린 물체를 구분합니다. 목 마스크가 셔츠와 옷깃으로, 피부 마스크가 손·소매·응원봉 위로 번지지 않습니다.
- 마스크 떨림 감소: 랜드마크를 화면 움직임에 맞춰 안정화하고, 마스크를 얼굴 움직임에 맞춰 앞뒤 프레임과 평균합니다. 가림이 생긴 프레임은 그 프레임의 판단을 따릅니다.
- 얼굴의 페인팅, 그림, 문신, 그려 넣은 핏줄은 보정하지 않습니다.
- 줌으로 얼굴 크기가 바뀌거나 조명이 얼굴 위를 지나가도 보정 강도가 일정합니다.
- 팔자주름·입가주름: 실제 주름선만 채웁니다. 옆에서 비치는 조명의 볼 음영을 펴 버리던 문제와, 볼 위의 머리카락·그림 선을 주름으로 보고 밝히던 문제를 고쳤습니다.
- 보정 부위를 체크박스로 고릅니다: 얼굴, 목, 어깨·쇄골, 팔, 손, 다리 (여러 개, 최소 1개).
- K(피부 보정 영역)가 선택한 인물의 영역을 보여 줍니다 (슬라이더를 움직이기 전에도).
- 분석된 인물은 모두 보정 대상으로 시작합니다. 역할은 보정 / 보호 두 가지입니다.

**작업 관리**
- 컷 상태: 분석 전 · 작업 전 · 작업 중 · 완료 · 작업 불필요. 컷 리스트 필터, 타임라인 상태 표시, "작업 불필요 숨기기".
- 컷 오른쪽 클릭: 작업 완료, 작업 불필요, 버전 올리기 / 이전 버전으로 (모든 컷은 v1부터, 렌더 파일 이름에 _v1), 보정값 복사·붙여넣기.
- Ctrl+C / Ctrl+V: 컷 보정값 복사·붙여넣기 (같은 멤버끼리 자동으로 맞춤). Alt+V: 바뀐 값만 골라서 붙여넣기.
- 인물 Shift+클릭: 여러 인물에 같은 보정값.
- 컷 리스트 Shift / Ctrl 다중 선택.

**화면**
- 파란 계열 테마, 흑백 DIAP 로고, 로딩·저장 애니메이션.
- Z: 화면 맞춤, Ctrl+F: 전체 화면, Shift+F: 보정 탭과 미리보기만.
- 저장하지 않고 닫을 때 저장 / 저장 안 함 / 취소. Windows 종료 때는 자동으로 저장합니다.
- 자동 저장 간격과 보관 개수 설정. 설정에 버전 표시.
- 슬라이더를 움직이는 동안 미리보기가 빨라졌습니다.
- 다른 컷으로 바꾼 뒤 결과·원본·나란히·와이프에서 이전 컷이 보이던 문제, 컷을 눌러도 재생 전까지 화면이 안 바뀌던 문제, 재생 중 "미리 계산 전" 표시가 깜빡이던 문제를 고쳤습니다.
- 삭제: 변형량 히트맵, 통계·누적 학습 탭(학습은 자동으로 계속), QC 탭, 확인 기준, 벤치마크 등록, 분석 정밀도 선택(항상 최고 정밀), 학습 스위치.

**분석·프록시·출력**
- 편집 타임라인의 모든 컷이 베이크 영상의 프록시 하나를 같이 씁니다 (XML을 불러온 뒤 프록시를 다시 만들지 않음).
- 처음 프록시를 만들 때 해상도를 고릅니다.
- 분석 중에도 PC가 느려지지 않게 우선순위를 낮추고 CPU 2코어를 남깁니다. 다른 컷 작업 중 분석이 멈추던 문제를 고쳤습니다.
- 출력 기본값 ProRes 4444 XQ. 타임라인 출력 방식은 출력 탭에서, 렌더 탭에 "선택한 컷 추가"와 "전체 컷 일괄 렌더 (베이크)".
- 옷 그대로: 그 인물에게서 찾은 옷(상의·바지·치마·원피스)만 골라서 그대로 둡니다.
- 편집 파일 경고는 문제가 있을 때만 표시됩니다.

**비상업적 용도 전용**: 얼굴 분석 모델과 학습 데이터(CelebAMask-HQ)는 비상업적 사용만 허용됩니다.
