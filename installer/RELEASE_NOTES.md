## Contour 1.8.1

- 설치 파일(exe)로 설치하고, 새 버전이 나오면 앱에서 바로 업데이트할 수 있습니다 (프로젝트 메뉴 > 업데이트 확인). 업데이트는 확인을 눌러야만 설치되고, 프로젝트·학습 데이터·프리셋·모델은 그대로 남습니다.
- 실행할 때 비밀번호를 입력해야 합니다.
- 베이크 영상을 먼저 불러오고 시퀀스 XML을 나중에 끌어다 놓으면 컷이 나뉘지 않던 문제를 고쳤습니다. 이제 길이가 맞는 베이크 영상을 찾아 타임라인으로 나눕니다. 맞는 영상이 없으면 타임라인 불러오기 창이 열립니다.
- ffmpeg가 PC에 없으면 설치할 때 자동으로 받습니다.
