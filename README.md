# DIAP

(이전 이름 Contour. 코드 패키지 이름은 `contour` 그대로입니다.)

영상 속 인물의 몸매를 보정하는 Windows용 독립 앱입니다. 인물이 크게 움직이고 카메라가 흔들리는 K-pop 뮤직비디오를 기준으로 만들었습니다.

- 자동 추적: 인물 검출 → 포즈 모델 앙상블(RTMPose-x, RTMW-x, RTMPose-m, 최고 정밀에서 DWPose 추가) → 얼굴 106점·손 21점 전용 모델 → 광류 포인트 트래커와 양방향 융합
- 수동 수정: 관절을 끌어 놓으면 키프레임이 되고, 앞뒤 프레임이 자동으로 다시 계산됩니다
- 학습: 수정할수록 이 클립에 맞춰 바로 학습하고, 프로젝트가 쌓이면 누적 모델을 학습합니다
- 인물 분할: 추적한 인물마다 SAM 3.1로 정확한 실루엣을 따로 만들어 매트·윤곽 측정·다른 인물 보호에 사용
- 몸: 허리·위팔·아래팔·팔뚝살·어깨·직각 어깨·골반·힙업·뱃살·허벅지·종아리·다리 전체·무릎·목, 키·다리 길이, 몸 가로 비율
- 몸 윤곽 점: 팔·몸통·골반·어깨·다리 윤곽을 점 216개로 프레임마다 추적해 보정이 실제 실루엣을 따라가고, 점을 직접 끌어 원하는 부분만 다듬기
- 얼굴형: 얼굴 크기(얼굴만), 얼굴 길이, 하관, 턱선, 턱선 교정, 광대, 턱 끝 길이, 턱 끝 폭
- 이목구비: 눈 크기·세로·사이 거리·눈꼬리, 코 크기, 콧대 폭, 입 크기, 입꼬리, 인중, 얼굴 점을 직접 옮기는 세부 성형
- 머리: 머리 크기(머리카락 포함), 정수리, 헤어 볼륨
- 피부: 피부결, 잡티, 팔자주름, 입가주름, 다크서클, 번들거림, 홍조, 목주름, 목 닭살, 피부 밝기·톤·채도, 그레인(모노/색상, 크기)
- 프리셋: 슬라이더 값 묶음을 이름으로 저장해 다른 인물·컷·프로젝트에 적용
- 메이크업·색: 볼터치(색 조절), 쉐딩, 하이라이트, 입술 색조·채도·밝기, 치아 미백, 눈 흰자, 무릎 어두운 부분
- 뒤도는 인물: 돌아서는 동안에도 같은 인물·같은 좌우 관절로 이어지고, 머리 보정은 뒷모습에서도 유지
- 군무: 사람 재인식(몸 OSNet + 얼굴 SFace)으로 교차·대형 변경·화면 이탈 뒤에도 같은 사람에게 같은 번호. 어두운 무대·색 조명에서는 분석용 화면만 밝기·색을 맞춰 검출, 모션블러로 검출이 빠진 프레임은 포즈로 이어 붙임
- 옷 포함/제외: 몸 보정에 옷까지 함께 / 치마·원피스 아랫단은 그대로 / 옷은 모두 그대로
- 가려진 관절: 화면 밖으로 나가거나 가려진 팔다리는 자동으로 판단해 보정에 쓰지 않음
- 배경: 기본은 워프, 필요할 때 인물만 분리해 변형하고 가려진 배경을 이웃 프레임에서 복원
- 보호: 다른 인물·소품 보호, 배경 직선 보호(카메라 움직임을 자동으로 따라감), 겹침 자동 방지
- 확인: 전후 비교(결과/원본/비교/와이프, `\` 키로 A/B), 변형량 히트맵, 렌더 전 자동 QC, 미리 계산해 두는 실시간 재생
- 출력: ProRes 422 HQ / 4444 / 4444 XQ / 422, OpenEXR(half). 보정된 곳 외의 픽셀은 원본 코드값 그대로, 타임코드·색 태그 유지. 인물 매트와 변형 마스크 별도 출력
- 관리: 렌더 목록, 컷 간 설정 복사, 통계 대시보드(CSV), 모델 버전 관리와 되돌리기

## 설치

**필요한 것**: Windows 10/11 64비트, NVIDIA GPU 권장(RTX 4070 Ti 등), 인터넷(처음 설치 때), 여유 공간 약 6GB

1. 릴리스 페이지(github.com/kammy0328/Contour-Releases/releases)에서 `DIAP_Setup_x.y.z.exe`를 받아 실행합니다.
   - 관리자 권한 없이 `C:\Program Files\Diap`에 설치됩니다(관리자 권한 필요). Python은 설치 파일 안에 들어 있습니다.
   - 처음 설치할 때 패키지와 모델(약 1.1GB)을 받습니다. 10~20분 정도 걸립니다.
   - CUDA를 쓸 수 없으면 자동으로 DirectML로 바꿉니다. ffmpeg가 없으면 자동으로 받습니다.
   - 누적 학습 기능(PyTorch, 약 2.5GB)은 설치 화면에서 고릅니다.
2. 시작 메뉴나 바탕화면의 **DIAP**로 실행합니다. 실행할 때 비밀번호를 입력합니다.
   - Windows가 "PC 보호" 경고를 띄우면 "추가 정보 > 실행"을 누릅니다 (코드 서명이 없어서 뜹니다).

**업데이트**: 앱을 켜면 새 버전이 있는지 확인하고(설정의 `시작할 때 새 버전 확인`으로 끌 수 있음), 있으면 변경 내역과 함께 알려 줍니다. "지금 업데이트"를 눌러야만 받고 설치하며(받은 파일은 SHA-256으로 확인), 설치가 끝나면 다시 실행됩니다. Program Files에 설치되므로 업데이트 때 Windows 권한 확인 창이 뜹니다. "나중에"나 "이 버전 건너뛰기"를 고를 수 있고, 프로젝트 메뉴의 "업데이트 확인"으로 언제든 다시 확인할 수 있습니다. 모델·학습 데이터·프리셋·통계는 `문서\Contour_Data`에 있어서 업데이트해도 그대로 남습니다. 받은 설치 파일은 `문서\Contour_Data\updates`에 최근 3개가 남아 있어 이전 버전을 다시 설치할 수 있습니다.

**소스에서 실행(개발용)**: `install.bat` 후 `run.bat`.

## 작업 순서

1. **프로젝트** 왼쪽 위 프로젝트 메뉴 → 새 프로젝트. 폴더 이름의 공백은 `_`로 바뀝니다.
2. **컷 추가** 왼쪽 `+` 또는 파일을 창에 끌어다 놓기. ProRes, H.264, MXF, EXR·DPX·TIFF 시퀀스.
   - 로그 소스는 출력 탭에서 입력 색공간(S-Log3, LogC3/4, V-Log, DWG 등)이나 뷰 LUT를 고르면 화면과 분석이 보기 좋게 바뀝니다. 렌더 결과의 픽셀 값은 바뀌지 않습니다.
   - 긴 소스는 `I` / `O`로 작업 구간을 먼저 정하면 분석이 빨라집니다.
3. **분석** 추적 탭 → 분석 시작. 정밀(권장)은 모델 앙상블, 2차 정밀 추정, 얼굴·손 전용 모델, SAM 2 인물 분할까지 합니다. 최고 정밀은 DWPose와 좌우 반전 추정, 더 큰 SAM 2 모델을 써서 2배쯤 느리지만 관절이 가장 덜 떨립니다.
   - **뒤도는 인물** 프레임마다 얼굴 랜드마크의 눈 사이 거리와 얼굴 크기를 그 인물이 정면일 때와 비교해 정면·옆·뒷모습을 판단합니다(포즈 모델과 얼굴 검출기는 뒷머리에도 얼굴이 있다고 답하는 경우가 많아 판단에 쓰지 않습니다). 한 프레임 안에서는 모든 포즈 모델의 좌우 라벨을 다수 의견에 맞추고(평균 내다 손목이 몸 가운데로 모이는 일 방지), 샷 전체에서는 관절이 프레임 사이에 튀지 않고, 정면에서는 인물의 왼쪽이 화면 오른쪽, 뒷모습에서는 화면 왼쪽에 오도록 좌우를 골라 돌아서는 동안에도 같은 관절로 이어집니다. 인물 연결은 좌우가 바뀌어도 같은 사람으로 보고, 돌아서며 겉모습이 바뀌어도 바로 이어지는 위치면 같은 인물로 합칩니다. 뒷모습에서는 얼굴 보정이 자연스럽게 빠지고, 머리 크기·정수리·헤어 볼륨은 마지막으로 보인 얼굴 위치를 이어 받아 계속 적용됩니다. 몸 점 편집도 인물 기준의 바깥쪽·왼쪽에 붙어 있어 돌아서도 같은 자리에 남습니다.
   - **군무** 추적 탭의 `사람 재인식 (군무)`가 켜져 있으면(기본) 사람마다 몸 생김새(OSNet 재인식 모델)와 얼굴(SFace)을 기억합니다. 서로 엇갈려 지나간 뒤 번호가 바뀌었는지는 지나가기 전후의 생김새·얼굴·진행 방향으로 다시 따져 바로잡고, 다른 멤버 뒤에 가려졌다가 나오거나 화면 밖으로 나갔다 들어온 사람은 얼굴이 보이면 얼굴로, 아니면 진행 방향과 생김새로 원래 번호에 이어 붙입니다. 같은 의상을 입은 군무에서는 얼굴이 가장 확실한 단서라, 얼굴이 정면으로 잘 보이는 프레임이 많을수록 정확합니다.
   - **어두운 장면·색 조명·모션블러** 화면이 어둡거나 한 가지 색 조명이 강하면 분석 모델에 넘기는 화면만 밝기를 올리고, 색 조명은 깨끗한 흑백으로 바꿉니다(출력에는 영향 없음). 모션블러로 검출기가 사람을 놓친 프레임은, 그 사람이 혼자 서 있을 때에 한해 직전 위치에서 포즈를 다시 찾아 이어 붙입니다. 다른 사람과 겹친 구간은 엉뚱한 사람에게 붙는 것을 막기 위해 이어 붙이지 않고 사람 재인식에 맡깁니다.
- **SAM 2 인물 분할** 추적 탭의 `SAM 2 인물 분할`이 켜져 있으면(기본) 인물마다 따로 정확한 실루엣을 만듭니다. 몸 윤곽 점, 다른 인물 보호, 분리 모드, 머리 윤곽이 모두 이 매트를 씁니다. 이미 분석한 컷은 `인물 매트만 다시 만들기`로 다시 분석하지 않고 바꿀 수 있고, 관절을 많이 고친 뒤에 누르면 고친 추적으로 매트를 다시 만듭니다.
4. **인물 지정** 피부·몸매 탭의 인물 칩을 누르고 `보정 대상 / 보호 / 제외`를 고릅니다. 보정 대상이 아닌 사람은 기본으로 보호됩니다. 사람이 아닌 것이 잡혔거나 필요 없는 인물은 이름 옆 휴지통으로 지웁니다. 다시 분석해도 돌아오지 않습니다.
   - **번호가 바뀐 군무 구간** 추적 탭 아래 `인물 정리`에서 고칩니다. 한 사람이 두 번호로 나뉘었으면 `인물 합치기…`, 두 사람이 엇갈린 뒤 서로의 번호를 달고 가면 인물을 고른 뒤 `번호 바로잡기…` → `두 인물 맞바꾸기`(지금 프레임부터 끝까지, 또는 타임라인에서 고른 구간), 추적이 엉뚱한 사람을 따라갔으면 `새 인물로 떼어 내기`. 관절 수정과 숨김 표시, SAM 2 인물 분할도 함께 옮겨지고, 보정 값은 인물 이름에 남아 있어 바로잡는 순간 맞는 사람에게 적용됩니다.
5. **보정** 슬라이더는 몸, 키·비율, 얼굴형, 이목구비, 머리, 피부, 메이크업·색 그룹으로 접혀 있습니다. 쓰고 있는 그룹에는 분홍 점이 붙습니다. 구간마다 값이 달라야 하면 ◇를 눌러 키프레임을 만드세요.
   - **몸** − 쪽이 가늘게입니다. 위팔은 어깨선 아래부터 적용돼 어깨는 움직이지 않습니다. 목은 턱과 얼굴을 건드리지 않습니다. 몸 슬라이더는 추적된 몸 윤곽 점을 따라 움직여, 종아리 곡선이나 허리 잘록한 곳처럼 위치마다 다른 폭이 그대로 반영됩니다.
   - **팔뚝살·뱃살** `팔뚝살`은 위팔의 처지는 쪽(팔을 들면 아래쪽, 내리면 바깥 뒤쪽) 윤곽만 넣고, 몸통은 따라 움직이지 않습니다. `뱃살`은 배 앞쪽 윤곽을 넣으며 옆모습일수록 크게, 정면에서는 거의 들어가지 않습니다.
   - **어깨·골반** `직각 어깨`는 처진 어깨 끝을 올려 어깨선을 반듯하게, `골반`은 허리 아래 엉덩이 옆선을 넓히거나 좁힙니다. `힙업`은 엉덩이 아래 선을 올리며 뒷모습·옆모습에서 잘 보입니다.
   - **몸 점 편집** 몸 그룹의 `몸 점 편집`을 누르면 어깨·위팔·아래팔·몸통·골반·허벅지·종아리 윤곽에 점이 보입니다. 점을 안팎으로 끌면 이웃 점이 부드럽게 따라오고(`Shift`를 누르고 끌면 그 점만), 한 프레임에서 만든 모양이 몸을 따라 모든 프레임에 적용됩니다. 오른쪽 클릭: 그 점 되돌리기, Esc: 끝내기. 세기는 `몸 점 편집` 슬라이더로 조절합니다. 점은 결과 화면에서 지금 보이는 윤곽 위치에 그려집니다.
   - **옷** 몸 그룹 아래 `옷`에서 `함께 보정`(기본), `치마 그대로`, `옷 그대로`를 고릅니다. `치마 그대로`는 치마와 원피스의 허리 아랫단을 원래 모양으로 두고 다리·허리만 보정하며, `옷 그대로`는 상의·하의·신발·모자·가방까지 그대로 두고 드러난 몸(팔·다리·목·얼굴)만 보정합니다. 처음 고를 때 옷 영역 분석 모델(약 110MB)을 받고 인물의 옷을 한 번 분석합니다(GPU에서 1080p 70프레임에 수 초~수십 초). 매트 보기(`M`)에서 그대로 두는 옷이 주황 빗금으로 보입니다.
   - **경계 부드러움** `전체 강도` 아래 슬라이더로 모든 모양 보정이 주변으로 퍼지는 정도를 정합니다. 올리면 경계가 더 넓고 부드럽게 섞이고, 내리면 해당 부위에만 좁게 들어갑니다. 몸 점 편집에서 이웃 점이 따라오는 범위도 이 값을 따릅니다.
   - **키·비율** 키는 목 아래부터 발목까지, 다리 길이는 골반부터 발목까지 세로로 고르게 늘립니다. 발은 바닥에 그대로 붙어 있고 몸이 위로 자랍니다. 그래서 바닥, 그림자, 광택 바닥에 비친 모습, 발 아래 화면은 움직이지 않고, 몸 위쪽 배경만 그 사람 주변에서 함께 올라갔다가 옆과 위로 갈수록 자연스럽게 원래 자리로 돌아옵니다. 옆 사람은 따라 늘어나지 않고, 레터박스(위아래 검은 띠)는 건드리지 않습니다. 배경이 조금도 움직이면 안 되는 컷은 `분리 + 배경 복원` 모드에서 쓰세요.
   - **얼굴 세부** `광대`는 옆으로 나온 광대만, `턱 끝 길이`와 `턱 끝 폭`은 턱 끝만 바꿉니다(− 폭이 V라인). 이목구비 그룹의 `눈 세로`, `눈 사이`, `눈꼬리`(+ 올림), `입꼬리`(+ 올림), `인중`(− 짧게)은 해당 부위만 움직이고 주변은 부드럽게 따라옵니다.
   - **얼굴형** 얼굴 크기는 얼굴 윤곽 안쪽만 바뀌고 머리카락과 배경은 얼굴 가장자리 바로 바깥에서만 따라 움직입니다. 머리카락까지 함께 줄이려면 머리 그룹의 `머리 크기`를 쓰세요. 턱선은 턱 곡선을 따라 둥글게 들어가고, 턱선 교정은 매끈한 턱 곡선보다 튀어나온 곳(각진 턱, 울퉁불퉁한 곳)만 안쪽으로 깎아 다듬습니다. 바깥으로 밀거나 움푹 들어가게 하는 일은 없고, 좌우 맞춤은 정면을 볼 때만 조금 들어갑니다(돌아본 얼굴의 좌우 차이는 각도 때문이라 맞추지 않습니다).
   - **세부 성형** 이목구비 그룹의 `점 편집`을 누르면 얼굴 점(윤곽 49점 포함 111점)이 보입니다. 한 프레임에서 점을 끌면 그 모양이 얼굴을 따라 모든 프레임에 적용되고, 윤곽 점은 이웃 점이 함께 움직여 선이 매끈하게 유지됩니다. 오른쪽 클릭: 그 점 되돌리기, Esc: 편집 끝내기. 세기는 `세부 성형` 슬라이더로 조절합니다.
   - **피부** `피부결`과 `질감 유지`로 매끈함과 모공을 조절합니다. 팔자주름·입가주름은 주름 골의 그늘만 주변 피부 밝기까지 채워 펴고, 원래보다 어두워지는 일은 없으며 결은 남깁니다. 피부 밝기·톤·채도·그레인은 눈가와 이마 끝까지 얼굴 피부 전체에 들어가고 눈동자·흰자·입술만 빠집니다.
   - **홍조·목주름** `홍조`는 볼·코 주변의 붉은 기를 그 얼굴의 피부색으로 가라앉히고 입술은 건드리지 않습니다. `목주름`은 목의 가는 가로 주름 골만 채우고 목 그늘과 결은 남깁니다. `목 닭살`(1.5.1)은 목의 오돌토돌한 닭살 결과 그 붉은 얼룩을 눌러 부드럽게 만듭니다. 100에서도 결의 15 % 정도와 필름 그레인 크기의 결은 남겨 지운 티가 나지 않고, 목걸이 반짝임·옷깃·목 그늘처럼 닭살보다 훨씬 강한 디테일은 건드리지 않습니다. 목 범위는 턱선 아래에서 시작해 이 얼굴의 피부색으로 거르고, 목 앞의 손·팔(누구 손이든), 얼굴보다 확연히 밝은 흰 털 옷깃·흰 셔츠는 뺍니다. 어깨가 화면 밖이거나 머리카락·옷에 가려져도 턱선 기준으로 잡습니다.
   - **메이크업** `볼터치`는 광대 앞쪽 볼에 블러셔를 얹고 `볼터치 색`으로 핑크·로즈(−)에서 코랄·피치(+)까지 고릅니다. `쉐딩`은 콧대 옆, 광대 아래, 턱선 안쪽을, `하이라이트`는 콧대, 광대 위, 이마 가운데, 턱 끝을 밝힙니다. 모두 얼굴 점을 따라 움직입니다.
   - **잡티·다크서클·번들거림** `잡티`는 주변보다 어둡거나 붉은 작은 점(점, 트러블, 뾰루지)을 찾아 주변 피부로 메우고, 머리카락 가닥이나 주름처럼 길쭉한 것은 건드리지 않습니다. 지울 크기는 피부 그룹 아래 `잡티 크기`로 정합니다. `다크서클`은 눈 밑 어둡고 푸른 그늘을 볼 피부 밝기·색으로 끌어올리고, `번들거림`은 하얗게 뜬 유분 광만 눌러 줍니다. 모두 프레임마다 연속적으로 계산해 깜빡이지 않습니다. 그레인은 피부 영역에만 얹히며 `색상 그레인`이 0이면 모노크롬입니다. 범위는 `얼굴만` 또는 `얼굴 + 목·팔·다리`.
   - **메이크업·색** 입술 색조는 − 쪽이 핑크·보라, + 쪽이 코랄·오렌지입니다. 치아 미백과 눈 흰자는 누런 기와 실핏줄을 걷어 냅니다.
   - `K`를 누르면 피부·색 보정 영역이 분홍색으로 보입니다. 얼굴 크기 등 모양 보정을 따라 움직인 위치로 표시됩니다. 눈·눈썹·입술·콧구멍은 피부 영역에서 항상 빠집니다.
   - 슬라이더를 끄는 동안에는 미리보기가 조금 거친 해상도로 따로 계산되고, 손을 떼면 정밀하게 다시 그립니다.
   - **재생** 편집을 멈추면 작업 구간의 결과를 뒤에서 미리 계산해 둡니다. 타임라인 눈금 아래 초록 줄이 계산된 구간이고, 그 구간은 원래 속도로 재생됩니다. 아직 계산되지 않은 프레임은 재생 중 원본으로 보이고 화면에 `미리 계산 전`이 표시됩니다.
6. **추적 확인** 타임라인의 빨간 구간(신뢰도 낮음)을 `N` / `Shift+N`으로 오가며 관절을 끌어 고칩니다. 고친 내용은 앞뒤 프레임에 자동 반영되고, 이 클립에 맞춰 학습됩니다. 여러 곳을 고친 뒤에는 `수정 내용으로 전체 다시 계산`을 누르면 고치지 않은 구간까지 좋아집니다.
   - **안 보이는 관절** 가려지거나 화면 밖으로 나간 관절은 자동으로 빠집니다. 선택한 인물의 빠진 관절은 점선 고리로 보이고, 끌어 놓으면 그 위치로 다시 씁니다. 화면 밖으로 나간 팔다리는 점선으로 바깥 방향만 표시되고, 화면 안에 남은 부분은 계속 보정됩니다.
   - 자동 판단이 틀려서 보이지 않는 관절이 잡혀 있으면 관절을 오른쪽 클릭 → `안 보이는 관절로 지정`. 이 프레임만, 타임라인에서 고른 구간, 무릎부터 발목까지처럼 끝쪽 관절까지 한 번에 지정할 수 있습니다.
   - **프리셋** 인물 이름 아래 `현재 값 저장`으로 지금 값을 이름을 붙여 저장합니다. 담을 그룹(몸, 얼굴형, 피부 등)을 고를 수 있고, 불러올 때는 그 그룹만 바뀝니다. `프리셋 불러오기`에서 이 인물이나 이 컷의 보정 대상 모두에 적용합니다. 프리셋은 `문서\Contour_Data\presets`에 있어 모든 프로젝트와 새 버전에서 함께 씁니다.
7. **보호** 문틀·기둥·수평선은 `L`로 직선을 그리고, 마이크·소품은 타원/사각형으로 감쌉니다.
8. **QC** QC 탭 → QC 실행. 항목을 누르면 해당 프레임으로 이동합니다.
9. **렌더** 출력 탭 → 렌더에 추가 → 렌더 화면에서 렌더 시작. 코덱과 출력 경로는 렌더 화면에서 눌러 바꿀 수 있습니다(Ctrl+A로 모두 고른 뒤 누르면 한꺼번에). 같은 이름의 파일은 덮어쓰지 않고 `_v02`처럼 번호를 붙입니다.

다른 컷에도 같은 값을 쓰려면 피부·몸매 탭의 `다른 컷에 복사`를 누르세요. 인물은 얼굴(두 컷 모두에서 얼굴이 보였으면 얼굴이 우선, 의상이 바뀐 장면끼리도 연결), 몸 재인식, 옷 색으로 자동 연결되고, 직접 바꿀 수 있습니다. 아직 분석하지 않은 컷은 분석이 끝나는 순간 적용됩니다.

## 편집 타임라인 작업 (베이크 영상 + XML) · 1.6.0

뮤직비디오 전체를 한 번에 작업하는 방식입니다. 편집 프로그램에서 시퀀스를 통째로 뽑은 **베이크 영상**과 그 시퀀스의 **편집 파일**을 함께 불러오면 샷마다 컷이 하나씩 생깁니다.

1. **불러오기** 프로젝트 메뉴 `편집 타임라인 불러오기…`, 또는 편집 파일과 베이크 영상을 같이 끌어다 놓기. 이름 끝이 `_AFTER`인 영상을 같이 놓으면(다른 프로그램으로 뷰티 작업한 전체 길이 결과) 학습용으로 붙습니다.
   - 읽는 형식: Premiere Pro / Final Cut Pro 7 XML, FCPXML (Final Cut Pro X, DaVinci Resolve), CMX3600 EDL
   - 시퀀스 시간 기준으로 나눔: 시퀀스 시작 타임코드(예: 00:59:58:00, 01:00:00:00), 29.97/59.94 드롭프레임, 여러 비디오 트랙(위쪽 트랙이 보이는 것), 연결된 클립(FCPXML 레인), 꺼진 클립 제외, 빈 구간(검정)
   - 트랜지션(디졸브 등)은 두 샷이 섞인 구간이라 따로 컷으로 두고 기본은 원본 그대로
   - 속도 변경·중첩 시퀀스·복합 클립은 컷에 표시(ⓘ 정보에서 확인)
   - **영상과 대조**: 베이크 영상 전체를 작게 읽어 편집 경계마다 실제 화면 전환이 있는지 확인합니다. 영상이 다른 타임코드에서 시작했거나 앞에 여유 프레임이 붙어 있으면 어긋난 프레임 수를 찾아 맞춥니다. 화면 전환이 없는 경계, 편집 파일에 없는 큰 화면 변화(플래시나 빠진 컷)는 경고로 보여 줍니다.
2. **타임라인 줄** 화면 아래 썸네일 줄에 모든 컷이 편집 순서대로 보입니다. **↑ / ↓ 키로 이전 / 다음 컷**, 클릭으로 열기, Ctrl/Shift로 여러 컷 선택, 오른쪽 클릭으로 상태 지정·검수 표시·선택 컷 분석·프리셋 적용·내보내기.
3. **일괄 분석** 분석 전 컷을 차례로 분석합니다(컷마다 별도 프로세스라 메모리가 쌓이지 않고, 한 컷이 실패해도 나머지는 계속). 분석 전에 몇 프레임으로 인물이 있는지 먼저 보고 없으면 건너뛰어 프록시도 만들지 않습니다. 분석이 끝난 컷은 얼굴이 잘 보이는 인물을 모두 보정 대상으로 잡습니다(군무). 일괄 분석 중에도 다른 컷을 열어 작업할 수 있습니다(분석 중인 컷만 잠김).
4. **컷 상태** 분석 결과로 자동 판정하고 썸네일 아래 색 줄과 글자로 표시합니다. 직접 바꾼 상태는 진한 색으로 표시되고 다시 분석해도 유지됩니다.
   | 상태 | 판정 |
   |---|---|
   | 적용 양호 (초록) | 주요 인물(가장 큰 얼굴의 60% 이상이거나 샷의 60% 이상 등장) 얼굴 인식 80% 이상, 추적 신뢰 60% 이상 |
   | 인식 불량 (빨강) | 주요 인물 중 누군가 그 기준 미달 (이유 표시), 트랜지션, 분석 실패 |
   | 얼굴 작음 (노랑) | 얼굴 폭이 모두 60px 미만 (와이드샷, 리터칭 효과가 거의 없음) |
   | 리터칭 불필요 (회색) | 인물 없음, 얼굴이 보이는 인물 없음, 검정 구간 |
   | 제외 (보라) | 직접 지정: 내보낼 때 빼는 컷 |
   위쪽 상태 칩을 누르면 그 상태 컷이 모두 선택됩니다.
5. **일괄 적용** 선택한 컷(없으면 전체)의 보정 대상에 프리셋을 한 번에 적용합니다. 기본은 `학습된_스타일`(없으면 `수작업_기준`).
6. **검수** `검수`를 누르면 인식 불량 → 얼굴 작음 → 적용 양호 순으로 검수 안 한 컷을 엽니다. 확인(필요하면 수정)한 뒤 다시 `검수`를 누르면 검수 완료(✓)로 표시하고 다음 컷으로 갑니다.
7. **내보내기** (렌더 목록으로 들어감)
   - **전체 길이 한 파일**: 베이크 영상과 같은 길이·시작 타임코드·오디오. 리터칭이 필요 없는 컷은 원본 그대로 들어갑니다.
   - **컷별 개별 파일**: 컷마다 한 파일, 컷 이름과 그 컷의 타임코드.
   - **리터칭 컷만 + 교체용 XML**: 리터칭한 컷만 파일로 만들고, 베이크 영상을 V1, 리터칭 컷을 V2의 제자리에 놓은 XML(Premiere·Resolve에서 가져오기)을 함께 만듭니다.
   - 포맷: ProRes 422 HQ, ProRes 4444 XQ(알파 포함), H.265 10bit MP4(NVIDIA NVENC가 있으면 GPU, 없으면 x265; 보통/고화질/최고 화질).
   - 상태별로 내보낼지 고릅니다. 빼는 컷은 전체 길이 파일에서 **4444 XQ면 투명(알파 0)**, 다른 포맷이면 원본 그대로, 컷별·XML 방식이면 파일을 만들지 않습니다.
8. **인물 연결 (1.7.0)** 일괄 분석이 끝나면 여러 컷에 나오는 같은 사람을 자동으로 멤버로 묶습니다. 타임라인 줄의 `인물`에서 멤버마다 나오는 컷의 얼굴이 보이고, 노란 테두리는 연결이 확실하지 않은 곳입니다. 얼굴을 누르면 그 컷 열기, 맞음 확정, 다른 멤버로 옮기기, 따로 떼기를 할 수 있습니다. `이름`으로 멤버 이름을 정하면 모든 컷의 인물 이름이 바뀌고, `설정 복사`는 지금 열린 컷에서 그 멤버에 맞춘 피부·메이크업 보정값을 그 멤버의 모든 컷에 넣습니다(프레임 키는 컷마다 달라 복사하지 않음). 직접 정한 연결은 `자동 연결 다시`를 눌러도 그대로이고, 떼어 낸 사람은 원래 멤버와 다시 묶이지 않습니다. 고친 연결은 재인식 자가학습에 들어갑니다.
9. **수작업 결과로 학습** 다른 프로그램으로 작업한 결과도 씁니다. 그 프로그램이 컬러까지 바꿨으면 얼굴 바깥으로 전체 색 변화를 계산해 빼고 피부 보정만 비교하고, 얼굴 모양도 바꿨으면(리퀴파이 등) 광류로 위치를 맞춘 뒤 많이 움직인 곳은 비교에서 뺍니다. 전체 길이 결과는 컷마다 같은 구간을 잘라 비교합니다. 일괄 분석 중에 컷마다 바로 학습합니다.

## 안무영상 도구 (군무 추적 평가·학습 데이터)

K-pop 안무영상 여러 개로 군무 추적을 시험하고, 틀린 곳을 바로잡아 정답을 만들고, 버전마다 점수를 매기는 도구입니다. 앱 폴더의 `dance_tool.bat`을 실행하면 메뉴가 나옵니다. 결과는 `문서\Contour_Data\dance`에 쌓이고, 영상 파일은 읽기만 합니다.

1. **영상 분석** 폴더를 고르면 하위 폴더까지 모든 영상을 차례로 분석합니다(앱과 같은 검출·포즈·사람 재인식 모델, GPU 사용). 60fps 영상은 30fps로 솎아 분석합니다. 영상마다 사람끼리 많이 겹치고 번호가 끊겼다 이어지는, 가장 어려운 20초 구간 2개를 골라 `영상이름\seg01` 같은 폴더에 다음을 만듭니다.
   - `review.mp4` 사람마다 번호를 그린 확인용 영상. 왼쪽 위에 구간 안의 시간(초)과 프레임 번호
   - `sheet.jpg` 번호마다 등장 구간과 모습 4장
   - `fixes.txt` 고칠 곳을 적는 파일 (적는 법이 파일 안에 있습니다)
   - 중간에 멈춰도(창 닫기, Ctrl+C) 다시 실행하면 끝난 영상은 건너뜁니다. 처리 시간은 화면 속 인원 수에 비례하며, 진행 줄의 fps와 남은 시간으로 가늠할 수 있습니다.
2. **고칠 곳 적기** `review.mp4`를 보며 번호가 틀린 곳을 `fixes.txt`에 적습니다. `같음 12 3`(같은 사람), `바꿈 3 5 12.4`(그 시간부터 맞바꿈), `나눔 7 20.0`(그 시간부터 다른 사람), `제외 9`(사람이 아님). 다 봤으면 `확인완료` 앞의 `#`을 지웁니다.
3. **정답 만들기** 확인완료한 구간의 정답을 만들고, 고친 번호로 `review_정답.mp4`를 다시 그려 확인할 수 있게 합니다. 고친 내용이 이상하면 fixes.txt를 고쳐 다시 실행하면 됩니다.
4. **평가** 지금 버전의 군무 추적을 정답 구간 전부에 돌려 점수(IDF1: 같은 사람이 같은 번호를 끝까지 유지한 정도, 번호 바뀜 횟수)를 보여 주고 `평가_기록.txt`에 남깁니다. 새 버전이 나오면 같은 정답으로 다시 평가해 비교합니다.
5. **보낼 파일 만들기** 정답 구간의 번호·관절·재인식 특징과 sheet.jpg만 zip으로 묶습니다(영상은 들어가지 않습니다). 추적을 다듬을 때 이 파일을 쓰면 실제 안무영상 기준으로 맞출 수 있습니다.

명령줄로도 쓸 수 있습니다: `.venv\Scripts\python.exe tools\dance_batch.py analyze <폴더> --seg 30 --per-video 3` (구간 길이, 영상당 구간 수), `--max`(큰 모델, 느림), `--out <결과 폴더>`.

## 정확도와 학습이 동작하는 방식

- **앙상블** 모델마다 틀리는 프레임이 달라서, 관절마다 여러 모델과 두 번의 추정 결과를 가중 합산하고 서로 크게 다르면 신뢰도를 낮춥니다.
- **얼굴 융합** YuNet 얼굴 검출과 RTMW 얼굴 랜드마크로 머리 관절을 보정해 목·어깨선이 안정됩니다.
- **포인트 트래커** 광류로 관절을 따라가는 칼만 필터를 앞뒤 양방향으로 돌려 합칩니다. 두 방향이 어긋나는 프레임은 확인 대상으로 표시됩니다.
- **카메라 흔들림** 배경으로 카메라 움직임을 계산해, 스무딩은 몸 기준 떨림에만 적용합니다. 흔들리는 영상에서도 워프가 몸에 붙어 있습니다. 편집으로 넣은 급한 줌인(펀치인)이나 숨은 컷처럼 그림 자체가 바뀌는 곳에서는 추적과 스무딩을 새로 시작해, 관절이 앞 장면에 끌려가지 않습니다. 플래시·스트로브처럼 밝기만 바뀌는 프레임은 같은 장면으로 이어 갑니다.
- **보이는지 판단** 포즈 모델은 화면 밖이나 가려진 관절도 그럴듯한 위치에 찍습니다. 모델 점수, 화면 가장자리, 인물 매트, 그리고 이 인물의 팔다리 길이 비율을 함께 보고 판단합니다. 화면 가장자리에 몰려 찍힌 관절은 팔다리가 원래 길이로 이어지는 화면 밖 위치로 옮겨 방향만 씁니다.
- **얼굴 랜드마크** RTMW의 얼굴 68점을 두 번 추정해 합치고, 광류와 카메라 보정 스무딩으로 프레임 사이 떨림을 없앱니다. 얼굴 보정과 피부결 영역이 모두 이 랜드마크를 따라갑니다.
- **SAM 2 인물 분할** 프레임마다 SAM 2.1을 한 번 돌리고, 추적한 인물마다 박스와 몸 위 관절(양성 점), 겹친 다른 인물의 관절(음성 점)로 마스크를 따로 뽑습니다. 화면에서 작은 인물은 그 사람만 확대해 따로 계산합니다. 사람마다 어느 픽셀이 누구 것인지까지 나오므로, 서로 겹친 군무에서도 다른 인물 보호와 윤곽 측정이 정확해집니다. 추적하지 않은 사람·소품은 기존 RVM 매트로 유지됩니다.
- **사람 재인식** 검출된 사람마다 몸 재인식 특징(OSNet-IBN, 512차원)과, 얼굴이 정면에 가깝게 보이면 얼굴 특징(SFace, 128차원)을 뽑습니다. 프레임 사이 연결은 관절 위치(좌우가 바뀌어도 같은 사람), 박스 겹침, 몸 재인식, 옷 색을 함께 보고, 몸 재인식 기억은 다른 사람과 겹치지 않은 프레임에서만 갱신해 엇갈릴 때 옆 사람 모습이 섞이지 않습니다. 분석은 샷 전체를 보고 하므로, 끝난 뒤 두 사람이 겹쳤던 구간마다 전후의 몸·얼굴·진행 방향을 비교해 엇갈렸으면 바로잡고, 끊긴 조각들은 한꺼번에 짝을 지어(헝가리안 할당) 같은 시점에 사라졌다 나타난 두 사람도 서로 바뀌지 않게 잇습니다. 얼굴이 같은 사람으로 확실하면 연결을 확정하고, 확실히 다른 사람이면 연결하지 않습니다. 같은 사람이 두 박스로 잡히면(관절이 같으면) 하나로 합칩니다.
- **깜빡이는 조명·플래시 (1.5)** 스트로브나 플래시로 화면 밝기가 갑자기 바뀌어도 같은 장면으로 봅니다(밝기·대비를 맞춘 뒤 그림 구조만 비교). 그래도 그림이 크게 바뀌면 화면의 모서리점이 앞뒤 프레임 사이에서 이어지는지 봅니다. 진짜 컷에서는 거의 이어지지 않고(스네어 점프컷 6곳 모두 10 % 이하), 조명이 켜지거나 꺼지는 같은 장면에서는 25 % 이상 이어집니다(1.5.1).
- **편집 XML 컷 경계 (1.5.1)** 프로젝트 메뉴 → `편집 XML에서 컷 경계 불러오기` (또는 XML을 창에 끌어다 놓기). 프리미어/FCP7 XML(xmeml)에서 같은 파일을 쓰는 클립들의 편집점을 읽어, 그 컷의 추적이 정확히 그 프레임들에서만 새로 시작합니다. 점프컷이 들어간 플레이트처럼 비슷한 샷이 번갈아 나오는 경우에도 정확합니다. 파일 이름은 공백·밑줄·대소문자를 무시하고 맞춥니다(`스네어 플레이트.mov` = `스네어_플레이트.mov`). 이미 분석한 컷은 다시 분석해야 반영됩니다. 1.4까지는 플래시 프레임마다 추적과 스무딩을 새로 시작해 관절·얼굴점이 그 앞뒤에서 튀었습니다. 프레임 사이 광류(카메라 움직임, 관절·얼굴점 따라가기)도 밝기가 바뀌는 프레임에서는 주변 대비로 정규화한 화면에서 계산해 끊기지 않습니다. 파란 클럽 조명처럼 한 가지 색 조명만 강한 장면은 분석 모델에 깨끗한 흑백 화면을 넘깁니다(1.4까지는 약한 색 채널을 키우다 노이즈와 가짜 색이 생겨 인물 분할이 얼룩지던 문제). 출력에는 영향이 없습니다.
- **클로즈업 (1.5)** 얼굴이 화면을 크게 채우고 손을 들어 몸이 가려진 컷에서는 사람 검출이 팔 주변이나 두 사람에 걸쳐 박스를 그려 관절과 얼굴점이 흩어집니다. 얼굴 검출로 찾은 큰 얼굴마다 얼굴 기준 상반신 박스로 포즈를 다시 잡고, 같은 얼굴에 머리를 둔 잘못된 박스는 버립니다. 얼굴 106점 모델도 얼굴 검출 박스로 잘라 돌리고, 얼굴 밖으로 흩어진 전신 모델의 얼굴점은 버립니다. 프레임 사이에서는 같은 얼굴 박스를 이어 같은 사람으로 잇습니다.
- **얼굴점 엉킴 걸러내기 (1.5)** 얼굴 106점 모델은 모션블러, 30도 넘게 기운 고개, 자르는 범위에 따라 점마다 얼굴의 다른 부위에 찍힌 엉킨 결과를 내기도 합니다(입 윤곽이 꼬이거나 턱선이 앞뒤로 오감). 이마 포함, 얼굴만, 고개를 똑바로 세운 얼굴만의 세 가지로 잘라 돌려 얼굴 모양이 맞는 결과를 쓰고, 그래도 입·눈·턱선 중 엉킨 부위가 있으면 그 부위는 전신 모델의 얼굴점으로 대신합니다. 입술이 실제보다 작게 잡혀 팔자주름 채우기가 윗입술을 피부색으로 칠하던 문제가 이것으로 사라졌습니다. 테스트 컷 3개(플래시, 클로즈업 군중, 모션블러 클로즈업)에서 엉킨 얼굴 프레임 28 → 13 (남은 것은 팔·옷에 얼굴이 가려진 뒤쪽 인물). 두 모델 모두 엉킨 프레임(어두운 군중 속 흐리거나 돌아간 얼굴)은 얼굴 보정과 얼굴 피부 보정이 그 프레임에서 자연스럽게 빠집니다(테스트 6개 컷에서 엉킨 얼굴점에 보정이 걸리던 프레임 119 → 30, 주인공 얼굴은 변화 없음).
- **비디오 추적 (1.5, 실험)** 추적 탭의 `비디오 추적 (SAM 2, 실험)`을 켜면, 사람마다 SAM 2 비디오 메모리(처음 본 프레임, 최근 6프레임, 16개 객체 포인터)로 그 사람의 픽셀을 기억해 매 프레임 다시 찾고, 검출된 사람을 그 마스크에 맞춰 넘겨줍니다. 두 마스크가 한 사람에 겹치면 덜 확실한 쪽은 그 프레임을 기억하지 않아 다른 사람 모습이 섞이지 않습니다. 같은 의상 군무(공개 데이터, 처음 보는 구간 2개)에서 번호 유지(IDF1)가 한 구간은 73.3 → 81.6으로 올랐지만 다른 구간은 61.4 → 51.6으로 떨어졌고, 얼굴만 크게 나오는 클로즈업에서도 기존 방식이 더 안정적이어서 기본은 꺼 두었습니다(CPU용 512px 모델 기준 평가, GPU에서는 1024px 모델을 씁니다). GPU가 있을 때만 쓰며 처음 한 번 모델(약 190MB)을 받습니다.
- **머리 부위 인식 (1.5)** 몸매 탭 머리 그룹의 `머리 부위 인식`을 누르면 SAM 2로 프레임마다 머리카락과 얼굴을 따로 찾습니다. 헤어 볼륨은 머리카락에만 들어가고 얼굴 피부와 귀(귀 관절 위치)는 그대로 남으며, 머리 크기·헤어 볼륨의 머리 윤곽을 사람 전체 매트 대신 머리카락+얼굴로 재서 머리 옆에 든 손이나 팔이 머리로 잡히지 않습니다. 마스크 떨림이 보정에 옮지 않도록 앞뒤 2프레임을 얼굴 움직임에 맞춰 평균합니다. GPU에서 프레임당 약 0.1초, CPU에서는 수 초가 걸립니다.
- **몸 윤곽 점** 관절 사이 뼈대를 기준으로 어깨·위팔·아래팔·몸통·골반·허벅지·종아리마다 9개 위치, 양쪽 가장자리에서 인물 매트의 경계를 소수점 픽셀 단위로 찾고 화면의 밝기 경계에 맞춥니다. 점은 뼈대에 붙은 위치(부위, 길이 방향 위치, 좌우)로 기억되어 몸이 움직여도 같은 자리를 따라가고, 프레임 사이에서는 몸 크기에 맞춰 정규화한 값으로 튀는 측정을 걸러 부드럽게 이어집니다. 팔이 몸통에 붙었거나 두 다리가 한 치마 안에 있어 경계가 다른 부위 것이면 그 점은 측정하지 않고 기본 폭을 씁니다.
- **클립 학습** 고친 관절에서 이 인물의 관절 위치 습관(예: 치마 때문에 골반이 높게 잡힘)과 관절 주변 생김새를 배워 같은 클립의 다른 프레임에 적용합니다.
- **누적 학습** 고친 관절과 확정 구간이 `문서\Contour_Data\learning`에 쌓입니다. 누적 학습 화면에서 새 모델을 학습하면 따로 떼어 둔 데이터와 **벤치마크 컷**으로 평가해 현재 모델보다 나을 때만 적용합니다. 언제든 이전 버전이나 기본 모델로 되돌릴 수 있습니다. 학습 데이터는 이 컴퓨터 밖으로 나가지 않으며, 프로젝트 메뉴에서 프로젝트별로 끌 수 있습니다.
- **자가학습 (1.5.4)** 손으로 고친 관절이 없어도 분석할 때마다 영상에서 스스로 배웁니다(교사-학생 자기학습). 교사는 샷 전체를 앞뒤 두 방향으로 보고 광류·포즈 앙상블·얼굴 모델·팔다리 길이로 푼 자동 추적 결과입니다. 정답으로 쓰는 관절: 보이는 관절, 앞뒤 방향 결과가 일치, 뼈 길이 정상, 같은 샷 안에서 앞뒤 4프레임 안에 확실한 프레임이 있음, 손으로 고친 곳 제외. 한 프레임만 보면 모델들이 엇갈리거나 블러가 있지만 앞뒤 프레임으로 정해지는 어려운 프레임을 우선 모읍니다.
  - **모델 신뢰도 학습** 포즈 모델(RTMPose-x, RTMW-x, RTMPose-m와 두 번째 추정, 얼굴 모델)마다 관절별·블러 상태별(선명/흐림/모션블러)로 얼마나 정답에 가까웠는지 쌓아, 다음 분석의 프레임별 결합 가중치로 씁니다. 분석마다 다시 계산하며, 영상 하나씩 빼고 나머지로 배운 가중치가 뺀 영상에서 평균 1 % 이상 나아지고 어떤 영상도 3 % 넘게 나빠지지 않을 때만 적용합니다(`learning\fusion`).
  - **관절 보정 모델** 컷마다 최대 400개를 `learning\samples\*__auto.npz`로 저장(최근 60개 컷)하고, 마지막 학습 뒤 새 컷이 5개 또는 샘플 1,500개가 쌓이면 분석 뒤 백그라운드에서 새 버전을 학습합니다(PyTorch 필요). 처음 보는 컷으로 뗀 검증 데이터와 같은 데이터에 플래시·색 조명·블러·위치 오차를 씌운 화면에서 모두 나아지고, 직접 고친 관절·벤치마크에서 나빠지지 않아야 적용합니다.
  - **현재 측정 결과(1.5.4 개발 시점, 테스트 영상 14개)** 두 방식 모두 아직 기준을 넘지 못해 적용되지 않습니다: 모델 신뢰도는 다른 영상에서 평균 11 % 나빠졌고(영상마다 어느 모델이 잘 맞는지가 달라 일반화되지 않음), 관절 보정 모델은 처음 보는 영상에서 개선 0.02 %였습니다. 확인 장치가 이를 걸러 현재 인식이 나빠지지는 않습니다. 영상이 쌓이면서 기준을 넘으면 그때 자동으로 적용됩니다.
  - 한계: 교사(자동 추적) 자체가 확실하게 틀리는 경우는 배울 수 없습니다. 어려운 컷 몇 개의 관절을 고쳐 벤치마크로 등록하면 그 데이터가 가장 확실한 학습·평가 기준이 됩니다. 얼굴 랜드마크·사람 검출·재인식 모델 자체는 다시 학습하지 않습니다.
- **리터칭 스타일 학습 (1.5.3)** 원본과 그 원본을 직접 리터칭한 결과를 같이 끌어다 놓으면(이름 끝이 `_AFTER`, ` after`, `_retouched`, `_수정본`, `_보정본`; 같은 폴더에 있으면 원본만 넣어도 찾음) 결과 파일은 컷으로 추가되지 않고 원본 컷에 짝으로 붙습니다. 원본 분석이 끝나면 자동으로, 얼굴이 크게 잡힌 프레임 최대 4장에서 피부결·질감 유지·잡티·홍조·다크서클·팔자·번들거림·그레인 값을 바꿔 가며 리터칭해 보고, 얼굴 피부(눈·눈썹·입술 제외)에서 수작업 결과와 가장 가까운 값을 찾습니다(4K 기준 1~3분). 영상마다 결과가 `문서\Contour_Data\learning\retouch_style.json`에 쌓이고, 프리셋 `학습된_스타일`이 지금까지의 영상 전체에서 가중 중앙값으로 다시 만들어집니다(수작업에 더 가까워진 영상일수록 비중이 큼). 보정 안 한 것이 가장 가까운 영상(수작업이 점 하나만 지운 경우 등)은 프리셋에 반영하지 않습니다. 같은 원본을 다시 학습하면 그 영상 결과만 바뀝니다. 프로젝트 메뉴의 `수작업 결과로 리터칭 스타일 학습…`으로 직접 고를 수 있고, `학습된 리터칭 스타일 보기`에서 영상별 결과를 확인합니다. 프로젝트의 학습 데이터 포함을 끄면 자동 학습도 하지 않습니다. 학습되는 것은 슬라이더 값이며, 수작업처럼 특정 얼룩만 골라 고치는 판단 자체를 배우는 것은 아닙니다.
- 벤치마크는 관절을 충분히 확인한 컷에서 추적 탭 → `벤치마크 등록`으로 만듭니다. 군무, 모션블러, 가림이 있는 어려운 컷을 몇 개 등록해 두면 학습 효과를 숫자로 볼 수 있습니다.

## 문제 해결

- **분석이 느림** 상단의 `추론:` 표시를 확인하세요. CPU면 NVIDIA 드라이버를 최신으로 업데이트한 뒤 `install.bat`을 다시 실행하세요. 설정에서 추론 장치를 고를 수도 있습니다.
- **ffmpeg를 찾지 못함** 설정(오른쪽 위 톱니) → ffmpeg 폴더.
- **오류 내용 확인** `run_debug.bat`으로 실행하면 창에 로그가 보입니다. 로그 파일은 `문서\Contour_Data\logs\contour.log`.
- **디스크 공간** 컷마다 프록시와 매트 캐시가 프로젝트 폴더의 `cuts\<id>\cache`에 생깁니다(1080p 30초 기준 약 6GB). 지워도 컷을 다시 열면 새로 만듭니다.

## 알려진 한계

- 군무에서 사람끼리 심하게 겹치거나 팔다리가 오래 가려지는 구간은 자동 추적이 틀릴 수 있습니다. 빨간 구간을 확인하고 고쳐 주세요.
- 같은 의상에 얼굴이 작거나 뒤돌아 있는 멤버들이 오래(1~2초 이상) 뭉쳐 있다가 흩어지면 번호가 서로 바뀔 수 있습니다. 몸 재인식만으로는 같은 의상을 잘 구분하지 못하고, 화면에서 얼굴이 작으면(폭 50px 안팎) 얼굴 인식도 흔들리기 때문입니다. 바뀐 구간은 추적 탭의 `번호 바로잡기…`로 고쳐 주세요.
- 옷 영역 분석 모델(SegFormer-B2 옷 분할)은 NVIDIA SegFormer 라이선스상 비상업 연구·평가 용도로만 배포됩니다. 처음 쓸 때 안내가 나오며, 상업 작업에 쓰기 전에 사내 확인이 필요합니다. 기본 설치에는 포함하지 않고 `옷` 옵션을 처음 고를 때 받습니다.
- 분리 모드는 인물이 거의 움직이지 않으면 가려진 배경을 이웃 프레임에서 찾기 어려워 공간 인페인팅을 씁니다. QC가 알려 주며, 그런 컷은 워프 모드를 권장합니다.
- 몸 윤곽 점은 보이는 실루엣을 따라가므로, 폭이 넓은 치마·코트처럼 옷이 몸에서 떨어져 있으면 옷 윤곽이 함께 줄어듭니다. `범위 조절`로 폭을 줄이거나 몸 점 편집으로 원하는 곳만 다듬으세요.
- 렌더는 워프 모드에서 프레임 여러 장을 동시에 처리하고, 첫 프레임에서 GPU 워프(ONNX Runtime CUDA/DirectML)와 CPU 워프를 비교해 같은 결과이면서 빠른 쪽을 씁니다. 렌더 화면의 완료 메시지에 어느 쪽을 썼는지 나옵니다. 분리 모드와 인물 매트 출력은 프레임 순서대로 처리합니다.
- SAM 2 분할은 GPU에서 프레임당 약 0.1~0.3초가 더 듭니다. CPU만 쓰는 환경에서는 프레임당 수 초가 걸리니 추적 탭에서 끄거나 빠르게 모드를 쓰세요.
- 1.3 이전 컷의 매트는 RVM입니다. SAM 2를 쓰려면 추적 탭의 `인물 매트만 다시 만들기`를 누르세요.
- 몸 윤곽 점(어깨·골반 포함)은 이전 버전에서 분석한 컷을 처음 열 때 백그라운드에서 측정됩니다(1080p 70프레임 기준 약 10초). 그동안은 1.2 방식의 폭으로 동작합니다.
- 누적 학습은 수정 데이터가 수백 개 이상 쌓여야 효과가 커집니다.
- 1.0에서 분석한 컷은 가려진 관절 판정, 얼굴 보정, 피부결 보정을 쓰려면 다시 분석해야 합니다. 관절 키와 보정 값은 그대로 남습니다.
- 손 추적과 얼굴 106점 모델은 1.2에서 다시 분석해야 쓰입니다. 그 전에는 1.1의 얼굴 68점으로 동작합니다.
- 1.1까지의 `팔` 값은 위팔·아래팔에 같은 값으로 옮겨집니다. 1.1의 `얼굴 크기`는 머리카락까지 함께 줄였기 때문에, 같은 값이라도 1.2에서는 결과가 다릅니다.
- 키·다리 길이는 몸이 위로 자라는 만큼 머리 위 배경이 함께 올라갑니다. 머리가 화면 위 끝에 닿은 컷은 값을 작게 쓰세요.
- 머리 크기·헤어 볼륨은 워프 모드에서 머리 주변 배경이 조금 함께 움직입니다(바뀌는 양의 약 3배 거리에 걸쳐 원래 자리로 돌아옴). 배경이 복잡하면 분리 모드를 쓰세요. 머리 바로 옆에 든 손과 팔은 움직이지 않게 잡아 두지만, 머리를 아주 크게(30% 이상) 키우면 그 사이가 조금 휘어 보일 수 있습니다.
- 얼굴이 옆으로 많이 돌거나 화면에서 아주 작으면(얼굴 폭 약 40px 미만) 얼굴 보정과 얼굴 피부결 보정이 자연스럽게 약해집니다. `얼굴 + 목·팔·다리` 범위에서 얼굴 랜드마크를 못 찾은 프레임은 머리 전체를 피해서 적용합니다.

### 1.11.0

**전체 분석, 전체 피부 보정**
- 컷 리스트 맨 위에 `전체 분석`과 `전체 피부 보정` 버튼을 추가했습니다. 타임라인 스트립의 `일괄 분석`도 같은 기능입니다.
- 전체 분석: 분석 전인 컷을 모두 차례로 분석합니다(컷 리스트에서 여러 컷을 선택했으면 그 컷만). 시작 창에서 컷 수, 프레임 수, 예상 소요 시간과 끝나는 시각을 보여 주고, `분석이 끝난 컷에 피부 기본 조정 적용`을 고르면 컷마다 분석이 끝나는 대로 보정 대상 인물에 넣습니다.
- 진행 창이 앱을 덮어 그동안 다른 조작은 되지 않습니다. 프로그레스바, `n / N컷 · 지금 컷 이름 %`, 지난 시간, 남은 시간, 끝나는 시각이 나옵니다. 예상 시간은 이 PC에서 잰 프레임당 분석 시간으로 계산하고(처음에는 프레임당 2초로 가정), 컷이 끝날 때마다 실제 속도로 고칩니다. 잰 속도는 설정에 남아 다음 예상에 씁니다.
- 일시정지는 분석 프로세스를 그 자리에서 멈추고(GPU 메모리는 그대로), 계속을 누르면 이어서 진행합니다.
- 취소: `지금 컷까지 마치고 멈춤` 또는 `바로 멈춤`. 끝난 컷은 모두 분석 완료로 남고, 바로 멈추면 진행 중이던 컷의 분석은 버리고 그 컷은 분석 전으로 둡니다.
- 전체 피부 보정: 기본 조정(강도, 입가주름·팔자주름·여드름 보호/제거)을 분석된 모든 컷의 보정 대상 인물에 넣습니다. `피부 값을 손으로 조정한 인물은 건너뛰기`(기본 켬)는 세부 조정에서 직접 맞춘 인물을 그대로 둡니다. 키프레임이 있는 피부 항목은 컷 전체 값으로 바뀝니다.

**분석 완료 표시**
- 컷 리스트와 타임라인 썸네일에 분석 완료는 초록 체크, 마지막 분석이 실패한 컷은 빨간 느낌표와 `분석 실패`가 붙습니다. 컷 필터에 `분석 완료`와 `분석 실패`를 추가했습니다.

**미리보기창의 인물**
- 마우스를 올리면 그 사람 영역이 색으로 칠해지고 외곽선과 이름이 나오며 커서가 손가락으로 바뀝니다. 클릭하면 선택됩니다.
- 우클릭 메뉴: 이 인물 선택, 이름 변경, 보정/보호 바꾸기, 이 인물 삭제. 이름 변경은 같은 사람으로 연결된 모든 컷(기본) 또는 이 컷만 고를 수 있습니다. 삭제한 인물은 다시 분석해도 돌아오지 않습니다.

### 1.10.0

**피부 · 몸매 탭**
- 오른쪽 패널의 `보정` 탭을 `피부`와 `몸매`로 나눴습니다. 인물 선택, 보정/보호, 프리셋은 두 탭 위에 똑같이 있습니다.
- `몸매`: 방식, 전체 강도, 경계 부드러움, 몸, 키·비율, 얼굴형, 이목구비, 머리.
- `피부`: `기본 조정`과 `세부 조정`. 세부 조정은 지금까지의 피부 슬라이더 전체와 메이크업·색, 질감 유지, 그레인 크기, 잡티 크기, 보정 부위입니다.
- 기본 조정은 세부 조정의 프리셋입니다. 보정 강도(약하게 / 표준 / 강하게)와 입가주름·팔자주름·여드름 각각 보호 / 제거를 고르면 세부 조정 슬라이더에 값이 바로 들어갑니다. 세부 조정에서 피부·색 값을 하나라도 바꾸면 기본 조정의 선택 표시가 해제되고 값은 그대로 남습니다.

| 팔자주름 제거 | 25 | 40 | 60 |
| 입가주름 제거 | 25 | 40 | 60 |

- 보호는 0입니다. 피부 밝기·톤·채도, 그레인, 메이크업은 기본 조정이 바꾸지 않습니다. 기본 조정은 컷 전체 값으로 들어가고, 키프레임이 있는 항목은 키프레임을 지울지 먼저 묻습니다. 아무것도 고르지 않은 상태에서 보호/제거를 누르면 강도는 표준으로 들어갑니다.
- `초기화`는 그 탭의 값만 처음으로 돌립니다(피부 탭: 피부·색, 몸매 탭: 모양).

**시작, 열기, 저장**
- 시작 화면: 실행하면 바로 DIAP 로고와 회전 애니메이션이 뜨고, 구성 요소를 불러오는 동안 계속 돕니다.
- 프로젝트 열기: 프로젝트와 컷 미리보기를 백그라운드에서 읽고, 화면에는 진행 상황(컷 미리보기 n/N)이 나옵니다. 그동안 창이 멈추지 않습니다.
- 자동 저장은 이제 복구본만 만듭니다(프로젝트 폴더 `autosave\recovery.json`). `project.json`은 저장할 때만 바뀝니다. 그래서 자동 저장이 지난 뒤에도 닫을 때 저장 / 저장 안 함 / 취소를 묻고, 저장 안 함을 고르면 마지막으로 저장한 상태 그대로 남습니다. 저장하지 않고 프로그램이 끝났으면 다음에 열 때 복구할지 묻습니다. 컷을 바꾸거나 분석이 끝날 때 저장되는 것은 이전과 같습니다.
- 설정에 `시작할 때 새 버전 확인`을 추가했습니다(기본 켬). 새 버전이 있으면 시작할 때 지금 업데이트 / 나중에 / 이 버전 건너뛰기를 묻고, 설치가 끝나면 DIAP이 다시 켜집니다. 꺼도 프로젝트 메뉴 > 업데이트 확인으로 확인할 수 있습니다.

**속도**
- 피부 마스크: 같은 얼굴의 피부 확률을 사람마다 두 번 계산하던 것을 한 번으로 줄이고, 프레임 색 평면을 그 프레임의 모든 인물이 같이 씁니다. ILLIT 3컷 18프레임에서 마스크는 비트 단위로 같고 보정 준비 시간이 419초에서 326초로 22% 줄었습니다.

### 1.9.7

**영상 읽기**
- H.264 MP4처럼 영상이 파일 시작보다 늦게 시작하는 파일(B-프레임 MP4, 0.041초)은 프레임을 찾아갈 때 한 프레임 앞을 읽었습니다. bake에서 나눈 모든 컷이 앞 컷의 마지막 프레임으로 시작하고 마지막 프레임이 빠졌습니다. 이제 영상 시작 시점을 더해 찾아갑니다. 지금까지 쓴 4444XQ mov와 2611 bake는 시작 지연이 0이라 영향이 없습니다.
- ffmpeg 9에서 8bit 4:2:0 영상을 원래 크기 그대로 16bit RGB로 바꾸면 색이 깨졌습니다(초록이 거의 0). 크기를 줄이지 않는 경우(1920 원본의 1920 프록시 등) 프록시 색이 틀어져 분석과 피부 색 모델이 틀린 색 위에서 돌았습니다. 크기를 줄일 때만 `area`를 씁니다.

**인물**
- 사진 판정: 몇 초 동안 포즈를 잡고 가만히 선 멤버가 사진으로 판정돼 보정에서 빠졌습니다(ILLIT 018II7RF). 움직이는 사람과 얼굴 크기와 머리 높이가 같은 줄에 선 인물은 사람으로 남깁니다.
- 찾기 모델로 추가하는 인물: 이미 추적 중인 사람의 일부(뒤에 선 멤버의 머리)를 새 사람으로 중복 추가하던 문제(ILLIT 213ZQ6YQ)를 고쳤습니다. 다시 추정한 골격이 기존 사람과 겹치면 추가하지 않고 그 픽셀을 원래 사람에게 줍니다.
- `(추가)`, `(확인)` 인물이 분석 뒤 자동 보정 대상 지정에서 보정으로 바뀌던 문제를 고쳤습니다. 사용자가 바꾸기 전까지 보호로 남습니다.

**피부 보정**
- 한 사람이 두 추적으로 잡혀 같은 얼굴을 둘 다 가진 경우(잡지를 눈 아래까지 든 컷), 얼굴은 매트가 주는 쪽 한 번만 보정합니다. 이전에는 두 번 보정되고 두 번째 마스크가 잡지 위로 번졌습니다.
- 떨림 방지: 앞뒤 프레임이 둘 다 있을 때만 섞습니다. 컷의 첫·끝 프레임에서 마스크가 한쪽으로 끌려 얼굴의 4분의 1이 빠지던 문제를 고쳤습니다.
- 얼굴 색이 거의 한 가지인 컷(클리핑, 단색 조명)에서 피부 모델이 비어 NaN이 되던 문제를 고쳤습니다.
- 검증: ILLIT 1013_4444XQ 37컷, lngshot 'wanna go' v3 105컷(분석과 스킨 보정 적용, 마스크가 다른 사람·배경·피부 아닌 곳에 걸리는지, 덮는 비율, 연속 프레임 튐, NaN 검사).

### 1.9.6

**추적 교정 (SAM 3.1 인물 찾기로)**
- 빌린 골격 교정: 뒤에 있는 사람의 얼굴로 만든 추적에 포즈 모델이 앞사람 몸을 잡는 경우가 있었습니다(컷 53). 두 추적의 관절이 한 사람의 마스크 안에 같이 있으면, 박스가 그 마스크와 덜 맞는 쪽의 포즈를 자기 마스크 위에서, 다른 사람을 가린 이미지로 다시 추정합니다. 같은 사람의 팔이나 머리 같은 일부 마스크는 다른 사람으로 보지 않고, 다시 추정이 안 되면 그대로 둡니다.
- 정체 뒤바뀜 교정: 연속 프레임에서 마스크와 골격이 둘 다 "A가 B로 넘어갔다"고 할 때만 그 프레임부터 둘을 바꿉니다. 사람이 앞을 지나가거나 빠르게 움직이는 경우는 바꾸지 않습니다.
- 놓친 인물 추가: 찾기 모델이 꾸준히 찾는데 추적에 없는 사람(앞사람에 가려 검출에서 빠진 뒷줄 댄서 등)을 다른 사람을 가린 이미지로 포즈를 추정해 추가합니다. 이름에 `(추가)`가 붙고 `보호`로 들어갑니다. 보정이 필요하면 `보정`으로 바꾸세요. 포즈가 확실하지 않거나, 화면을 덮는 전경 덩어리이거나, 움직이지 않는 그림(포스터)은 넣지 않습니다. 바닥에 비친 거꾸로 선 모습도 넣지 않습니다.
- 추적하지 않는 사람(엑스트라)은 라벨에 따로 표시해 옆 사람의 보정 영역에 섞이지 않습니다.
- 머리카락: RVM 매트가 그 사람을 확실히 잡을 때 머리 주변 마스크 바깥의 가닥만 더합니다. 마스크 안쪽과 얼굴은 건드리지 않습니다.
- 검증: 2611 MV 23개 컷에서 같은 추적 위로 이전/이후 매트를 비교해 얼굴이 자기 라벨 안에 있는 수가 2,330에서 2,332(전체 2,377)로 유지됐습니다.
- 한계: 추적이 중간에 다른 사람으로 넘어가면서 골격이 바로 따라가지 않은 경우(컷 53의 0번)는 프레임마다의 라벨과 골격은 맞게 되지만 인물 번호가 바뀐 채로 남을 수 있습니다. 이때는 `인물 바꾸기`로 고치세요. 군중이 많은 컷은 `(추가)` 인물이 여러 명 생길 수 있습니다.

### 1.9.5

**인물 매트: SAM 3.1 인물 찾기**
- 프레임을 먼저 SAM 3.1의 "person" 찾기 모델로 사람마다 따로 나눈 뒤, 추적한 인물이 자기 관절과 박스가 들어가는 마스크를 받습니다(대응이 없는 인물은 보이는 얼굴이 들어 있는 마스크). 이 모델은 겹친 사람을 서로 나누도록 학습된 것이라 누가 앞이고 누구 팔인지를 영상에서 직접 판정합니다. 이전에는 추적 점으로 한 사람씩 따로 마스크를 뽑아, 겹친 곳에서 앞사람 팔이 뒷사람에게 가거나 어두운 옷이 조각나거나 머리카락이 빠졌습니다.
- 화면에서 작은 인물은 확대한 영역에서 같은 방식으로 받습니다.
- 찾기 모델에 대응이 없는 추적 인물만 이전의 점 방식으로 만들고, 찾은 사람 위로는 올라가지 못합니다. 얼굴이 보이는 인물은 얼굴 주변 마스크를 그대로 둡니다.
- 찾기 모델이 붙어 있는 두 사람을 하나로 낸 프레임에서는 그 안에서 점 방식으로 둘을 나눕니다.
- 추적하지 않는 사람(엑스트라)은 매트에 들어가고 누구의 라벨도 받지 않습니다.
- 찾기 모델이 사람으로 확인한 프레임이 20% 미만인 새 추적 인물(광택 벽에 비친 그림자, 반사)은 `보호`로 두고 이름에 `(확인)`을 붙입니다. 실제 사람이면 `보정`으로 바꾸면 됩니다.
- 처음 쓸 때 찾기 모델 약 120MB를 받고, 이 컴퓨터에서 GPU용으로 한 번 변환합니다(`onnx` 패키지 필요, GPU 설치에 포함). 변환하지 못하면 이전 방식으로 동작합니다. "person" 문구의 인코딩 결과는 앱에 들어 있어 700MB 문구 인코더는 받지 않습니다.
- 프레임당 약 0.1초, 작은 인물이 많은 컷은 0.5초쯤 더 걸립니다.
- 이미 만든 매트는 그대로입니다. 바꾸려면 `인물 매트만 다시 만들기`를 누르세요.
- 한계: 머리카락 가닥은 마스크 해상도(288px) 때문에 여전히 나오지 않습니다. 추적이 한 사람에게 두 개 붙은 컷은 라벨이 두 번호로 나뉠 수 있습니다. 추적에서 빠진 뒤쪽 인물은 매트에는 들어가지만 보정 대상이 아닙니다.

### 1.9.4

- 인물 분할을 SAM 2.1에서 SAM 3.1로 바꿨습니다(`seg_sam31`, 모든 정밀도). 처음 분석할 때 모델 약 940MB를 받습니다. 불러오지 못하면 SAM 2.1로 자동으로 돌아갑니다.

- 머리 부위 인식(`parts.py`)은 아직 SAM 2.1을 씁니다.
- 이미 만든 인물 매트는 SAM 2.1 결과 그대로입니다. 바꾸려면 `인물 매트만 다시 만들기`를 누르세요.

### 1.9.3

**Log 영상 (S-Log3, ARRI LogC3, LogC4)**
- 보정은 원본에서 계산합니다. Rec.709 화면은 미리보기와, 무엇을 지키고 어디를 보정할지 찾는 용도(점, 페인트, 머리카락, 주름, 색 키)로만 씁니다. 피부결 보정은 원본 밝기 면에서 직접 하고, 이후 단계가 화면에서 바꾼 양은 그 자리의 변환 기울기로 원본에 되돌려 넣습니다.
- 보정하지 않은 픽셀은 코드값이 그대로 남습니다. 서브샘플된 색차는 변화량의 영역 평균을 받습니다.
- log 입력 색공간으로 지정된 영상에만 적용되고, 일반 Rec.709 영상은 이전과 같은 경로입니다.
- 한계: 색차 매끄럽게 하기, 이후 접힘과 주름 단계의 변화는 아직 화면 값을 원본으로 되돌려 반영합니다. 화면에서 값이 잘려 있는 매우 밝거나 어두운 픽셀은 되돌릴 수 없어 변화를 제한합니다.
- log 영상은 변환 때문에 컷당 렌더 시간이 약 2~3배 늘어납니다. 얼굴 주변만 변환합니다.

### 1.9.2

- 얼굴에 놓인 밝은 선도 보호 대상으로 판정합니다. 페인트와 밝은 머리카락 같은 선은 색이 피부와 다르면 대비가 약해도 건드리지 않습니다. 보호할 선의 최소 길이를 얼굴 폭의 7%로 줄였습니다.
- 영상이 흐려지는 프레임에서 덜 지우는 기능은 앞뒤 프레임과 선명도 측정이 맞지 않는 컷(어두운 컷에서 밝은 컷으로, 줌, 플래시)에서는 따르지 않습니다.
- 대비가 큰 선을 밝기만으로 찾아 보호하는 기능(`FS_LINE`)을 넣었지만 기본값은 꺼 두었습니다. 피부의 긴 패임까지 보호해 기준 프레임의 보정이 약해졌습니다.

### 1.9.1

**피부 질감 보정 (2611 MV 작업 기준)**
- 피부결 보정을 레퍼런스 손 보정에서 맞춘 방식으로 바꿨습니다. 모공, 패임, 요철 대역마다 같은 비율로 줄이고, 가장 고운 입자는 그대로 둡니다. 켜졌다 꺼지는 문턱이 없어서 프레임 사이에 패임이 켜졌다 꺼지지 않습니다.

- 영상이 흐려지는 프레임에서는 덜 지웁니다(선명한 프레임을 더 지우지는 않습니다).
- 이마 눈썹 위 띠를 피부로 채워 마스크 구멍으로 보정이 켜졌다 꺼지던 문제를 줄였습니다.
- 점 판정 기준을 0.14에서 0.30으로 올렸습니다.

- 몸: 직각 어깨, 골반, 힙업, 팔뚝살, 뱃살. 몸 윤곽 점에 어깨선과 골반 추가. 위팔 보정이 겨드랑이 아래 몸통을 끌고 가던 문제 수정
- 프리셋 저장·불러오기 (그룹 선택, 인물·컷 단위 적용, 프로젝트 공유)
- 군무 추적: 사람 재인식(몸 OSNet-IBN, 얼굴 SFace), 엇갈림 구간 자동 교정, 끊긴 조각 일괄 연결, 낮춘 검출 기준과 중복 박스 제거, 모션블러로 놓친 프레임 포즈 이어 붙이기, 어두운 장면·색 조명 분석 보정
- 컷 간 복사의 인물 연결에 얼굴·몸 재인식 사용 (의상이 바뀐 장면끼리도 연결)

- 분석 속도: 사람마다 옷 색을 화면 전체가 아니라 그 사람 영역에서만 계산 (군무 컷에서 1차 분석이 빨라짐, 결과는 같음)
- 옷 포함/제외: 함께 보정, 치마 그대로, 옷 그대로 (옷 영역 분석)
