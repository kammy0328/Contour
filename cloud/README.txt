DIAP Cloud 폴더

data\<프로젝트>\<컷>\    DIAP가 영상을 분석하면서 모은 얼굴 원본 크롭 (512px JPEG)과 meta.json.
                         이 컴퓨터에만 저장되고 어디로도 전송되지 않습니다.
step_train.bat           개발자용. 프로젝트 하나를 골라 DIAP 자체 얼굴 파서를 이어서 학습합니다.
                         지금 쓰는 파서(비상업 라이선스)는 교사로만 쓰고, 가중치를 공유하지 않는 다른 신경망
                         (ResNet-34 기반)을 가르칩니다. 교사와의 일치율이 0.90 이상이 되면 앱에 설치합니다
                         (face_parse_own.onnx).
_trained\               학습을 마친 프로젝트 데이터 보관 (다음 학습에 섞여 이전 프로젝트를 잊지 않게 함).
model\                  이어 학습용 가중치 (face_parse_own.pt).
history.json             학습 기록 (프로젝트, 스텝, 학습 전후 일치율).
