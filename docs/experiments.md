# 모델 실험 제안 (기본 구성 변경 전 비교 필요)

기본 모델 구성은 바꾸지 않는다. 아래 실험은 실제 영상에서 같은 기준으로 비교한 뒤, 모든 항목이 기존과 같거나 나을 때만 기본값으로 올린다.

## 공통 비교 기준

- 영상: 2611_1MxKPDH_PV, lngshot_wanna_go_v3, ILLIT_1013의 분석 컷(군무·겹침·화면 이탈·재등장·모션 블러·색 조명·log 포함)
- 정답: 사람이 확인한 관절(benchmark.py에 등록한 컷)과, 사람이 고친 인물 연결. 자동 결과를 정답으로 쓰지 않는다. 학습·검증은 영상 단위로 나눈다.
- 측정:
  - 관절 오차(전체, 가림 구간, 블러 구간)
  - 인물 번호 혼동(ID 전환 횟수)
  - 마스크 IoU와 프레임 간 흔들림(같은 사람 마스크의 경계 변화)
  - 얼굴 인식 비율과 피부 보정 벤치마크(skinbench.py) 지표
  - 컷당 처리 시간, 단계별 시간, VRAM 최대치
- 실행: PC(RTX 4070 Ti 12GB)에서 사용자 프로젝트를 복사한 별도 프로젝트로. 결과는 jobs/out에 JSON으로.

## 지금까지 측정된 사실 (2026-11-17, j2680~j2682)

- 분석 시간의 80~90%는 SAM 3.1 인물 분할(인코더)이다. 포즈 모델은 호출당 5~50ms.
- SAM 3.1 인코더는 단독 0.41초/회. GPU 메모리가 11.7GB/12GB 근처로 차면 2~37초/회로 느려진다(드라이버의 시스템 메모리 대체로 보임).
- FP16 인코더(onnxruntime float16 변환)의 마스크는 FP32와 IoU 0.998 이상.
- TensorRT는 이 PC에 nvinfer가 없어 쓸 수 없다.

## 실험 1: 선택적 포즈 앙상블

- 기본: RTMW-x 하나. RTMW의 관절 신뢰도가 낮거나, 모델 간 불일치(disagree)·가림·블러·낮은 추적 신뢰도 구간에서만 RTMPose-x, DWPose-L, 좌우 반전 TTA를 추가.
- 기대 효과: 포즈 단계 시간 감소. 다만 포즈 단계가 전체의 10% 안팎이라 전체 시간 이득은 작다(측정상).
- 위험: 쉬운 프레임으로 판정했다 틀리면 관절이 튐. 가림·회전 구간의 관절 오차와 ID 전환을 반드시 비교.

## 실험 2: SAM 3.1 기준 프레임 + SAM 2 비디오 전파

- 방식: SAM 3.1을 기준 프레임(컷 시작, 인물 등장, N프레임마다, 추적 신뢰도가 떨어질 때)에만 돌리고, 사이는 SAM 2.1 비디오 추적으로 마스크를 전파. 주기적으로 SAM 3.1로 다시 고정.
- 기대 효과: 인코더 호출 수 감소로 분석 시간 큰 폭 감소, VRAM 압박 완화.
- 위험: 겹침·교차·화면 이탈 후 재등장에서 마스크가 다른 사람으로 넘어가거나 사라짐. 마스크 IoU, 흔들림, ID 전환을 기존(매 프레임 SAM 3.1)과 비교. 기준 프레임 간격별(4, 8, 16)로 측정.

## 실험 3: 메모리 압박 줄이기 (모델 교체 없이)

- 세션 옵션: CUDA 메모리 풀 요청량만큼 확장(kSameAsRequested), 유휴 스레드 spin 끄기, 스레드 수.
- SAM 3.1 인코더 FP16.
- 분할 단계 동안 쓰지 않는 세션 내리기.
- 측정: 컷당 시간, VRAM 최대치, 마스크 IoU(기존과 0.995 이상이어야 함). j2682가 이 비교를 하던 중 중단됨.
